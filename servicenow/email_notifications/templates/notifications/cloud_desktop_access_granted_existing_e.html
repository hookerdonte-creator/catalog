You have been granted access to ${variables.select_cloud_desktop_profile} Cloud Desktop.

Please wait approximately four hours before proceeding with the steps listed below.

  1. Visit the following URL: https://nvdi.nvidia.com/dashboard
  2. Click the "Create Cloud Desktop" button.
    • Enter a name for the desktop (e.g., jdoe-win11-cloud-desktop)
    • For "Profile", select the profile you are entitled to
    • For "Region", select the region that applies to your location
    • Click Submit
  3. Your NVIDIA Cloud Desktop will begin provisioning. This may take up to 30 minutes.
  4. While the desktop is provisioning, download the "Amazon DCV Client" application:
    • Visit this URL: https://www.amazondcv.com/latest.html
    • Download the appropriate "Amazon DCV 2025.0 Client" for your endpoint
    • Important: If using a Windows device, enable "USB Device remotization" during application installation
  5. After installing the viewer, return to the Cloud Desktop portal:
    • https://nvdi.nvidia.com/dashboard
    • Bookmark this link! You will always access your Cloud Desktop from this web portal, not directly from the Amazon DCV Client desktop application.
  6. Locate your Cloud Desktop and click the "Connect" button.
    • When prompted, check "Always allow nvdi.nvidia.com to open links…" and click "Open"
  7. The DCV Viewer application will open, and your workstation will load.
